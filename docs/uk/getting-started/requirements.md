# Вимоги

Для використання PROJECT YFA потрібні:

- сумісний Android-пристрій;
- застосунок PROJECT YFA;
- сумісний USB CAN-адаптер;
- USB-з'єднання між Android-пристроєм та адаптером;
- відповідне підключення адаптера до CAN-шини автомобіля.

Поточний адаптер для розробки побудований на **Waveshare RP2350-CAN** з прошивкою CANnectivity/Bridle gs_usb.

## Перед підключенням

Працюйте із застосунком лише тоді, коли взаємодія з Android-пристроєм є безпечною. Початкове налаштування, пошук несправностей і діагностичні перевірки слід виконувати на нерухомому автомобілі.
