# Перше підключення

Для першого підключення:

1. Переконайтеся, що PROJECT YFA встановлено та він відкривається.
2. Підключіть USB CAN-адаптер до інтерфейсу автомобіля.
3. Підключіть адаптер до Android-пристрою.
4. Надайте PROJECT YFA дозвіл USB, якщо Android його запитає.
5. Відкрийте PROJECT YFA та перевірте стан адаптера.
6. Відкрийте **Live Signals** і запустіть отримання даних.

Якщо зв'язок працює, декодовані значення сигналів почнуть оновлюватися.

## Якщо значення не оновлюються

Спочатку перевірте USB-з'єднання. Потім переконайтеся, що адаптер визначено і на CAN-шині є трафік. Див. [Усунення несправностей](../troubleshooting/index.md).
