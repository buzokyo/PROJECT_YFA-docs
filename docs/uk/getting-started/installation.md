# Встановлення

CANly можна встановити з каналу розповсюдження, який використовується для поточної збірки. Під час розробки та тестування це може бути локально встановлений APK або тестовий реліз Google Play.

Після встановлення відкрийте **CANly** та переконайтеся, що головний інтерфейс завантажується, перш ніж підключати USB CAN-адаптер.

## Дозвіл USB

Android контролює доступ застосунків до USB-пристроїв. Під час першого підключення Android може запитати, чи дозволити CANly доступ до USB CAN-адаптера PROJECT YFA, а також запропонувати пов'язати цей USB-пристрій із CANly.

Надайте доступ, щоб CANly міг обмінюватися даними з адаптером. Якщо вибрати опцію Android для запам'ятовування/асоціації USB-пристрою з CANly, наступні підключення кабелю можуть автоматично відкривати CANly без повторного запиту USB-дозволу.
