# Встановлення

PROJECT YFA наразі є проєктом у розробці, а не загальнодоступним застосунком із магазину застосунків.

Встановіть відповідний APK PROJECT YFA на Android-пристрій способом, який використовується під час розробки проєкту.

Після встановлення відкрийте PROJECT YFA та переконайтеся, що головний інтерфейс завантажується, перш ніж підключати USB CAN-адаптер.

## Дозвіл USB

Android контролює доступ застосунків до USB-пристроїв. Після підключення адаптера Android може запитати дозвіл для PROJECT YFA. Надайте доступ, щоб застосунок міг обмінюватися даними з адаптером.
