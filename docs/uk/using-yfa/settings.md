# Налаштування

Відкрийте **Налаштування** у PROJECT YFA, щоб змінити параметри програми. Поточний екран налаштувань поділено на три вкладки: **Вигляд**, **Підключення** та **Запис**.

Налаштування зберігаються програмою та залишаються чинними після закриття екрана налаштувань.

## Вигляд

### Тема

**Тема** керує зовнішнім виглядом програми. Доступні варіанти:

- **Системна** — використовувати тему системи Android;
- **Темна**;
- **Світла**.

Вибрана тема застосовується одразу.

### Не вимикати екран

**Не вимикати екран** визначає, чи повинна програма просити Android залишати дисплей увімкненим під час зчитування даних.

Цей параметр увімкнений за замовчуванням. Якщо його вимкнути, під час зчитування діятиме звичайний тайм-аут екрана Android.

## Підключення

### Адаптер

Селектор **Підключення** визначає апаратний транспорт, який використовує PROJECT YFA.

**Bluetooth ELM327** вибирає транспорт Bluetooth Classic для адаптерів ELM327/Vgate.

**USB CANnectivity** вибирає нативний транспорт gs_usb, який використовується з адаптером Waveshare RP2350-CAN для розробки PROJECT YFA.

Зміна цього параметра лише вибирає транспорт; підключення адаптера виконується окремо на головному екрані.

!!! note "Примітка"
    Деякий старий опис у самій програмі все ще називає USB CANnectivity транспортом лише для RAW CAN. Поточна USB-реалізація PROJECT YFA також підтримує Пасивний UDS і Активний UDS. Розділ цього посібника про USB CAN-адаптер описує поточну реалізацію.

### Вимкнути індикатор USER

Коли вибрано **USB CANnectivity**, перемикач **Вимкнути індикатор USER** керує USER LED адаптера Waveshare.

Налаштування зберігається в PROJECT YFA, а не у flash-пам'яті адаптера. Під час кожного відкриття USB-адаптера застосунок повторно надсилає збережений стан через runtime-команду прошивки PROJECT YFA.

- **Увімкнено** — USER LED примусово вимкнений, включно зі звичайною індикацією CAN RX/TX.
- **Вимкнено** — повертається звичайне керування індикатором прошивкою.

Якщо користувач перемикає опцію з **увімкнено** на **вимкнено**, коли адаптер уже підключений, після застосування налаштування PROJECT YFA виконує одне коротке підтверджувальне блимання. При ввімкненні опції блимання немає — індикатор просто вимикається.

Перезапуск або від'єднання адаптера очищає runtime-прапорець у прошивці. Після наступного підключення PROJECT YFA знову застосовує збережене налаштування застосунку.

!!! note "Примітка"
    Для цієї опції потрібна прошивка PROJECT YFA з runtime-керуванням USER LED. Це не NVS/flash-постійне налаштування адаптера.

### Режим зчитування

### MQTT broker

**MQTT broker** налаштовує брокер, який використовується MQTT-транспортом телеметрії PROJECT YFA.

Діалог містить:

- **Host / IP address**;
- **Port**;
- необов'язкове **Username**;
- необов'язкове **Password**;
- **Base topic**;
- **TLS**.

Порт за замовчуванням — **1883**, а базовий topic:

```text
project_yfa/vehicle
```

Порт має бути в межах від 1 до 65535. Перед збереженням host і base topic не можуть бути порожніми. Початкові та кінцеві символи `/` видаляються зі збереженого base topic.

PROJECT YFA формує два topics на основі base topic:

```text
<base topic>/state
<base topic>/availability
```

Пароль MQTT зберігається із шифруванням на основі Android Keystore. Якщо програма знаходить пароль у старому відкритому форматі, він мігрується до нового сховища.

TLS перемикає між зашифрованим з'єднанням із брокером і звичайним MQTT. Вимоги до сертифіката та мережі визначаються конфігурацією MQTT-сервера.

!!! note "Примітка"
    Збереження параметрів брокера налаштовує MQTT-транспорт. Передавання MQTT-телеметрії вмикається або вимикається окремо елементом MQTT на головному екрані.

## Запис

### Каталог PROJECT YFA

**Каталог PROJECT YFA** вибирає один кореневий каталог Android document tree для файлових функцій застосунку.

PROJECT YFA отримує постійний дозвіл читання/запису для цього кореня та за потреби створює підкаталоги:

```text
logs/
debug/
exports/
metadata/
```

Журнали зчитування записуються в **logs/**, діагностика адаптера/MQTT — у **debug/**, CSV-експорт — у **exports/**, а метадані автомобіля та журналів — у **metadata/**.

Якщо журналювання ввімкнене під час запуску зчитування, але каталог PROJECT YFA ще не вибрано, застосунок може запросити його перед продовженням.

Зміна вибраного кореня змінює місце читання й запису всіх цих файлів.

### Діагностичний журнал адаптера

### Діагностичний журнал адаптера

**Діагностичний журнал адаптера** вмикає докладне діагностичне журналювання транспорту адаптера.

За замовчуванням цей параметр вимкнений. Увімкніть його під час дослідження проблем підключення, USB, CAN-транспорту або обміну з адаптером. Для звичайного використання немає потреби залишати його постійно ввімкненим.

Діагностичний журнал адаптера відокремлений від звичайного перемикача запису даних на головному екрані.

## Пов'язані сторінки

На сторінці **Live Signals** описано режими зчитування, вибір сигналів, графіки, звичайне журналювання та керування MQTT.

На сторінках **USB CAN-адаптер** описано USB-дозвіл, роботу з'єднання gs_usb, режими Raw CAN/Пасивний UDS/Активний UDS і прошивку Waveshare RP2350-CAN.
