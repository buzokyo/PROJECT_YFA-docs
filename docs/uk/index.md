# Посібник користувача CANly

Ласкаво просимо до документації CANly.

**CANly** — Android-застосунок для роботи з даними автомобіля, який розробляється в репозиторії PROJECT YFA. Він відображає та інтерпретує дані, отримані з CAN-шини та через UDS-обмін. Цей посібник описує як CANly, так і USB CAN-адаптер PROJECT YFA, який використовується для підключення до автомобіля.

## Що містить цей посібник

Матеріал побудовано навколо практичних завдань: підготовка обладнання, встановлення CANly, перше підключення, використання Live Signals, налаштування сигналів і сповіщень, робота з журналами та MQTT і пошук типових проблем зі з'єднанням.

Посібник також слугує технічним довідником для розробки PROJECT YFA, тому поруч з інструкціями користувача можна зберігати важливі технічні пояснення.

!!! note "Примітка"
    CANly активно розробляється. Екрани, підтримувані сигнали, визначення ECU та діагностична поведінка можуть змінюватися між версіями.
