# Посібник користувача PROJECT YFA

Ласкаво просимо до документації PROJECT YFA.

PROJECT YFA — Android-застосунок для перегляду та інтерпретації даних автомобіля, отриманих із CAN-шини та через UDS-обмін. Цей посібник описує як сам застосунок, так і USB CAN-адаптер, який використовується для підключення до автомобіля.

## Що містить цей посібник

Матеріал побудовано навколо практичних завдань: підготовка обладнання, встановлення застосунку, перше підключення, використання Live Signals та пошук типових проблем зі з'єднанням.

Посібник також слугує технічним довідником для розробки PROJECT YFA, тому поруч з інструкціями користувача можна зберігати важливі технічні пояснення.

!!! note "Примітка"
    PROJECT YFA активно розробляється. Екрани, підтримувані сигнали, визначення ECU та діагностична поведінка можуть змінюватися між версіями.
