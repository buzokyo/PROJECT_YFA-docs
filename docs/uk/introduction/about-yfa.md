# Про CANly

**CANly** — Android-застосунок, що розробляється в межах PROJECT YFA для відображення та інтерпретації даних автомобільної CAN-шини.

Поточна версія поєднує кілька джерел даних:

- **RAW CAN** — сигнали, декодовані безпосередньо зі звичайного CAN-трафіку.
- **Passive UDS** — інформація з діагностичного обміну, який уже присутній на шині.
- **Active UDS** — діагностичні дані, які застосунок активно запитує у сумісних ECU.

CANly показує декодовані значення через **Live Signals** і містить допоміжну функціональність USB, CAN, журналювання, MQTT, метаданих автомобіля, графіків та сповіщень.

## CANly і PROJECT YFA

**CANly** — назва Android-застосунку, яку бачить користувач. **PROJECT YFA** — ширший проєкт розробки та GitHub-репозиторій, що також містить базу сигналів, документацію та ресурси/прошивку USB CAN-адаптера.

## Призначення документації

Цей посібник має дві цілі:

1. Допомогти користувачу працювати з CANly без необхідності знати його програмний код.
2. Зберегти технічні знання про CANly та USB CAN-адаптер PROJECT YFA для подальшої розробки.

Тому там, де це допомагає зрозуміти поведінку функції, додаються технічні пояснення.
