# Про PROJECT YFA

PROJECT YFA — Android-застосунок, створений для відображення та інтерпретації даних автомобільної CAN-шини.

Поточна версія поєднує кілька джерел даних:

- **RAW CAN** — сигнали, декодовані безпосередньо зі звичайного CAN-трафіку.
- **Passive UDS** — інформація з діагностичного обміну, який уже присутній на шині.
- **Active UDS** — діагностичні дані, які PROJECT YFA запитує у сумісних ECU.

Застосунок показує декодовані значення через **Live Signals** та містить допоміжну функціональність USB, CAN і діагностики.

## Призначення документації

Цей посібник має дві цілі:

1. Допомогти користувачу працювати з PROJECT YFA без необхідності знати його програмний код.
2. Зберегти технічні знання про застосунок і USB-адаптер для подальшої розробки.

Тому там, де це допомагає зрозуміти поведінку функції, додаються технічні пояснення.
