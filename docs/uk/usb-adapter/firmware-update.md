# Оновлення прошивки

Адаптер Waveshare RP2350-CAN для PROJECT YFA працює з перевіреною збіркою прошивки CANnectivity/Bridle для PROJECT YFA.

Використовуйте прошивку з цієї сторінки, а не універсальний upstream-образ CANnectivity. Збірка PROJECT YFA містить потрібну конфігурацію gs_usb і модифікацію з окремими RX/TX пулами буферів, з якою тестувався USB-транспорт.

## Завантаження прошивки

[**Завантажити прошивку PROJECT YFA (.uf2)**](https://github.com/buzokyo/PROJECT_YFA/raw/feature/user-manual/firmware/waveshare-rp2350-can/project-yfa-rp2350-can.uf2){ .md-button .md-button--primary }

**Плата:** Waveshare RP2350-CAN  
**Файл:** `project-yfa-rp2350-can.uf2`  
**Розмір:** 113 664 байти  
**UF2 blocks:** 222  
**SHA-256:**

```text
6479838C7243ABE683B8D5F98370518F022438FABF861C7D33FD884369F69AF8
```

Наданий файл є коректним UF2 firmware image для сімейства Raspberry Pi RP2350. Збережіть контрольну суму разом із завантаженим файлом, якщо хочете перевірити, що він не змінився та не був пошкоджений.

!!! warning "Попередження"
    Ця прошивка призначена для **Waveshare RP2350-CAN**, що використовується з PROJECT YFA. Не прошивайте нею інші плати RP2350, якщо самостійно не перевірили сумісність апаратної частини та призначення виводів.

## Перед оновленням

Зупиніть зчитування в PROJECT YFA та від'єднайте адаптер від CAN-підключення автомобіля перед переходом у bootloader.

Для самого оновлення потрібні лише адаптер і комп'ютер із USB. PROJECT YFA під час прошивання запускати не потрібно.

## Перехід у bootloader RP2350

1. Від'єднайте USB від адаптера.
2. Натисніть і утримуйте кнопку **BOOT** на платі.
3. Продовжуючи утримувати **BOOT**, підключіть адаптер до комп'ютера через USB.
4. Відпустіть **BOOT**, коли з'явиться boot drive RP2350.

Bootloader RP2350 представляє плату як USB mass-storage drive. Зазвичай він з'являється у файловому менеджері без встановлення окремої програми для прошивання.

Якщо плата вже живиться і кнопки доступні, перейти до ROM USB bootloader також можна відповідною комбінацією BOOT/RESET.

## Встановлення UF2

Скопіюйте `project-yfa-rp2350-can.uf2` на boot drive RP2350.

Після завершення копіювання bootloader програмує образ, після чого mass-storage drive зазвичай автоматично зникає, оскільки плата перезавантажується з новою прошивкою.

Не від'єднуйте плату багаторазово під час копіювання файла.

## Перевірка оновлення

Після перезавантаження плати:

1. Від'єднайте її від комп'ютера.
2. Підключіть до Android-пристрою з PROJECT YFA.
3. Надайте Android USB-дозвіл, якщо система його запитає.
4. Виберіть **Налаштування → Підключення → Адаптер → USB CANnectivity**.
5. Підключіть адаптер у PROJECT YFA.

Перевірена прошивка визначається через gs_usb як:

```text
VID: 0x1209
PID: 0xCA01
```

PROJECT YFA також очікує можливості прошивки, потрібні USB-менеджеру, зокрема listen-only та апаратні часові мітки.

Для функціональної перевірки спочатку запустіть Raw CAN, коли автомобіль нерухомий. Після підтвердження приймання Active UDS може додатково перевірити шлях передавання.

Поточна збірка повідомляє USB product string:

```text
Project YFA CAN-USB adapter
```

Якщо **Налаштування → Підключення → Вимкнути індикатор USER** увімкнено, підключіть адаптер і запустіть зчитування, яке зазвичай викликає активність USER LED. Індикатор має залишатися вимкненим. Якщо опцію вимкнено, повертається звичайна LED-індикація прошивки.

## Конфігурація прошивки

Ця збірка відповідає прошивці PROJECT YFA, описаній на сторінці **Waveshare RP2350-CAN**. Важливі параметри:

```text
CONFIG_USBD_GS_USB_POOL_SIZE=128
CONFIG_USBD_GS_USB_TX_POOL_SIZE=16
CONFIG_CAN_FD_MODE=n
```

Окремий TX-пул є модифікацією прошивки PROJECT YFA. Він не дозволяє безперервному CAN RX-трафіку використати буфери, потрібні для передавання від хоста до CAN.

Ця збірка також містить runtime-керування USER LED PROJECT YFA, яке використовує Android-опція **Вимкнути індикатор USER**. Стан у самому адаптері зберігається лише в RAM; PROJECT YFA зберігає налаштування та повторно застосовує його після перепідключення.

Історію змін прошивки дивіться на сторінці **Журнал змін прошивки**.

## Усунення проблем

### Диск RP2350 не з'являється

Від'єднайте USB і повторіть процедуру BOOT. Натисніть BOOT до повторного підключення USB та утримуйте кнопку, доки комп'ютер не визначить bootloader.

Якщо плата не визначається, спробуйте завідомо справний USB-кабель із передаванням даних та прямий USB-порт комп'ютера.

### Диск зникає після копіювання UF2

Зазвичай це нормальна поведінка. Після успішного копіювання UF2 RP2350 перезавантажується з нової прошивки, тому mass-storage drive bootloader зникає.

### PROJECT YFA не бачить адаптер після прошивання

Перепідключіть адаптер і перевірте USB-дозвіл Android. Переконайтеся, що в Налаштуваннях вибрано **USB CANnectivity**.

Якщо підключення все одно не працює, повторіть оновлення файлом із цієї сторінки та перевірте SHA-256 завантаженого файла.

### Raw CAN працює, але Active UDS — ні

Приймання Raw CAN саме по собі не перевіряє передавання USB/CAN. Для діагностики TX-шляху дивіться **Усунення несправностей** і розділ про архітектуру прошивки **Waveshare RP2350-CAN**.
