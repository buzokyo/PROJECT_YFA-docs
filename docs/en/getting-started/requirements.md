# Requirements

To use PROJECT YFA you need:

- a compatible Android device;
- the PROJECT YFA application;
- a compatible USB CAN adapter;
- a USB connection between the Android device and adapter;
- an appropriate connection from the adapter to the vehicle CAN bus.

The current development adapter is based on the **Waveshare RP2350-CAN** running CANnectivity/Bridle gs_usb firmware.

## Before connecting

Use the application only when it is safe to interact with the Android device. Initial setup, troubleshooting and diagnostic testing should be performed while the vehicle is stationary.
