# First connection

For the first connection:

1. Make sure PROJECT YFA is installed and can be opened.
2. Connect the USB CAN adapter to the vehicle interface.
3. Connect the adapter to the Android device.
4. Grant PROJECT YFA USB permission if Android asks.
5. Open PROJECT YFA and check the adapter status.
6. Open **Live Signals** and start data acquisition when ready.

When communication is working, decoded signal values should begin updating.

## If nothing updates

Check the USB connection first. Then verify that the adapter is detected and that CAN traffic is available. See [Troubleshooting](../troubleshooting/index.md).
