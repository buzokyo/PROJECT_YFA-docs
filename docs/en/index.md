# CANly User Manual

Welcome to the CANly documentation.

**CANly** is the Android vehicle-data application developed in the PROJECT YFA repository. It displays and interprets data obtained from CAN bus traffic and UDS communication. This manual documents both CANly and the PROJECT YFA USB CAN adapter used to connect it to the vehicle.

## What this manual covers

The manual is organized around practical tasks: preparing the hardware, installing CANly, making the first connection, using Live Signals, configuring signals and alerts, working with logs and MQTT, and diagnosing common connection problems.

It also serves as a technical reference for PROJECT YFA development, so implementation details can be recorded alongside user-facing instructions.

!!! note
    CANly is under active development. Screens, supported signals, ECU definitions and diagnostic behavior may change between versions.
