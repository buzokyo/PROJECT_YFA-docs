# PROJECT YFA User Manual

Welcome to the PROJECT YFA documentation.

PROJECT YFA is an Android application for viewing and interpreting vehicle data obtained from CAN bus traffic and UDS communication. This manual documents both the application and the USB CAN adapter used to connect it to the vehicle.

## What this manual covers

The manual is organized around practical tasks: preparing the hardware, installing the application, making the first connection, using Live Signals, and diagnosing common connection problems.

It also serves as a technical reference for PROJECT YFA development, so implementation details can be recorded alongside user-facing instructions.

!!! note
    PROJECT YFA is under active development. Screens, supported signals, ECU definitions and diagnostic behavior may change between versions.
